# cpp-course-homework
An artificial life ecosystem simulator developed for an Object-Oriented Programming (C++) course. The project models dynamic interactions between autonomous entities (Goat and Grass) on a 2D grid directly inside the terminal.  Features UsedInheritance & Virtual Functions: Derived Goat and Grass sub-classes from an abstract Creature base class to enforce a unified interface.  Polymorphism: Enabled dynamic method binding to process turn-based entity behaviors such as moving, eating, and spawning.  Dynamic Memory & Pointer Management: Managed dynamic object allocation, pointer tracking, and explicit memory cleanup across grid cells.
